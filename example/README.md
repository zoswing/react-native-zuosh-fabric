# React Native ZuoSh Fabric Example

This is an example app demonstrating the usage of `react-native-zuosh-fabric` CustomButton component.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. For iOS:
   ```bash
   cd ios && pod install && cd ..
   ```

3. Run the app:
   ```bash
   # For Android
   npm run android
   
   # For iOS
   npm run ios
   ```

## Features Demonstrated

- Basic button usage
- Custom colors (background and text)
- Disabled state
- Long press events
- Event handling and state management
